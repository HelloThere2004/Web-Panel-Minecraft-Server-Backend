# Minecraft Server Web Panel

[Read in Vietnamese](#phần-tiếng-việt)

A comprehensive web-based administration panel designed to manage and monitor a Minecraft server efficiently. This project provides a user-friendly interface for server administrators to control game states, manage worlds, and execute commands seamlessly.

## Features
* **Server Power Management:** Start, stop, and restart the Minecraft server effortlessly.
* **World Management:** Add existing maps or generate new worlds directly from the panel.
* **Real-time Logging:** Monitor server logs, events, and player activities in real-time.
* **Game Console:** An interactive web-based console to execute Minecraft commands and adjust game rules.
* **Version Control:** Update the Minecraft server version with minimal downtime.
* **Authentication & Authorization:** Secure login system to protect server access and panel controls.
* **Interactive UI:** A modern and responsive user interface tailored for seamless server management.
* **Automated Backups:** Schedule daily map backups and automatically upload compressed files to AWS S3 for data disaster recovery.
* **Resource Monitoring:** A visual dashboard using React charts to monitor real-time server metrics (CPU, RAM, and Disk usage).
* **Player & Whitelist Management:** View active player lists, toggle the server whitelist, and manage player access directly from the UI.

## Tech Stack
* **Front-end:** ReactJS
* **Back-end:** Node.js with Express.js
* **CI/CD:** GitHub Actions (Automated deployment pipeline for the Back-end)
* **Hosting/Deployment:** AWS Amplify (Front-end hosting)

# Trang Quản Trị Máy Chủ Minecraft (Web Panel)

[Đọc bản tiếng Anh](#minecraft-server-web-panel-)

Hệ thống quản trị web toàn diện được thiết kế để quản lý và giám sát máy chủ Minecraft một cách hiệu quả. Dự án này cung cấp một giao diện thân thiện giúp quản trị viên kiểm soát trạng thái trò chơi, quản lý bản đồ và thực thi lệnh trực tiếp trên trình duyệt.

## Tính Năng Chính
* **Quản lý Nguồn (Power):** Khởi động (Start), Dừng (Stop) và Khởi động lại (Restart) máy chủ Minecraft.
* **Quản lý Bản đồ (World):** Thêm bản đồ (map) có sẵn hoặc tạo thế giới mới trực tiếp từ giao diện web.
* **Nhật ký Thời gian thực (Logging):** Theo dõi log hệ thống và các sự kiện trong game theo thời gian thực.
* **Bảng Điều Khiển (Console):** Giao diện tương tác để gõ lệnh Minecraft, quản lý người chơi và cấu hình luật chơi (game rules).
* **Cập nhật Phiên bản:** Nâng cấp phiên bản lõi của máy chủ Minecraft một cách dễ dàng.
* **Xác thực & Phân quyền:** Hệ thống đăng nhập bảo mật, đảm bảo chỉ những người có quyền mới được can thiệp vào máy chủ.
* **Giao diện Người Dùng (UI):** Thiết kế hiện đại, trực quan giúp tối ưu hóa trải nghiệm quản trị.
* **Tự động Sao lưu (Auto Backup):** Lên lịch sao lưu bản đồ hàng ngày và tự động đẩy file nén lên AWS S3 để bảo vệ và khôi phục dữ liệu khi có sự cố.
* **Giám sát Tài nguyên (Resource Monitoring):** Tích hợp biểu đồ trực quan theo thời gian thực để theo dõi hiệu năng hệ thống (CPU, RAM, Ổ cứng).
* **Quản lý Người chơi & Whitelist:** Hiển thị danh sách người chơi đang online, bật/tắt Whitelist và quản lý quyền truy cập của thành viên trực tiếp từ giao diện.

## Công Nghệ Sử Dụng (Tech Stack)
